# Settings

| Setting | Scope | What it does |
| --- | --- | --- |
| Debug recorder → **Open the recorder** | GM | Opens the Debug Recorder window. |
| Stop recording after (minutes) | World | A recording stops by itself after this many minutes (5 to 240, default 30), so it can't run on by accident. |
| Open the recorder when the world loads | User | Opens the Debug Recorder window as soon as the world has loaded, for GMs only and in this browser only. On by default. |

## Keybinding

**Open the debug recorder** (GM only) under **Configure Controls**. No key is set by default.

## Kept by the module

Which modules are ticked in the window is remembered for the world, so the next recording starts with the same ones.
